02 · CIVILREPORT

A full-stack cross-platform mobile app that lets citizens report incidents such as accidents, fighting or vandalism. Reports go to a central server where other users can see them. Built for the Bincom Academy Mobile App Class test.

HTMLCSSJavaScriptApache CordovaWordPress REST APIJWT AuthCamera pluginGEO-LOCATION plugin
FEATURES & TECH ▾
  • User login with JWT authentication
  • Submit an incident with a title, category and description
  • Capture the incident's location (latitude and longitude)
  • Attach a photo of the incident
  • Live feed of all incidents, newest first
  • Filter by category, or show only your own reports
  • In-app notification when a new incident is posted (the app checks the server every 15 seconds)

Backend: WordPress, with each incident stored as a post. Built and tested with LocalWP, Node.js and the Android SDK; packaged as an Android APK.

03 · BLOG APP

A mobile-friendly blog app where users can sign up, log in, publish posts and read other people's posts. WordPress acts as the backend and database, and the app talks to it through JSON API calls written in JavaScript.

HTMLCSSJavaScriptApache CordovaWordPressJSON
FEATURES & TECH ▾
  • Sign up and log in
  • Publish a new blog entry
  • View all posts and filter them
  • Posts are stored on the server, so every user sees them
  • Can be packaged as an Android app with Cordova

Hosted on InfinityFree. Data is fetched with JavaScript fetch requests to the WordPress API.
