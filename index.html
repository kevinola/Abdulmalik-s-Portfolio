02CIVILREPORT
PROJECT IMAGE

CIVILREPORT

Report local incidents with a photo and location, synced live.
CordovaFirebaseLeaflet

A cross-platform mobile and web app that lets citizens report local incidents — crime/safety issues, hazards, vandalism, sanitation and power faults. Reports sync to Firebase in real time so other signed-in residents can see them instantly. Built for the Bincom Academy Mobile App Class test.

HTMLCSSJavaScriptApache CordovaFirebase FirestoreFirebase AuthenticationCloudinaryLeaflet / OpenStreetMapCamera pluginGEO-LOCATION plugin
  • Email/password sign-in with Firebase Auth and persisted sessions
  • Citizen profile with name, phone, state, LGA, street address and avatar
  • Capture the incident's location (latitude and longitude)
  • Attach a photo of the incident
  • Submit an incident with a title, category and description
  • Capture the incident's location by GPS, address lookup or a draggable map pin
  • Attach a photo or video from the camera or gallery (compressed, hosted on Cloudinary)
  • Live feed of all incidents, newest first, via Firestore real-time listeners
  • Filter by category, plus a "Your Reports" dashboard showing only your own posts
  • Real-time in-app community alerts for new incidents in your LGA, with an unread badge
  • Interactive map view with incident pins and one-tap emergency (tel:112) banner

Backend: Google Firebase — each incident is a document in the Firestore "reports" collection, readable only by email/password-authenticated users. Built and tested with Node.js, Firebase CLI and the Android SDK; packaged as an Android APK and also deployable to Firebase Hosting.

04MANGA APP
PROJECT IMAGE

MANGA APP

Komic: an Android manga reader with a built-in browser and an offline translator.
KotlinAndroid (native)

Komic is an Android manga reader built by me and a friend. We used an existing open-source Kotlin app from GitHub as the foundation and extended it with our own features. It pulls manga from several public manga APIs, and it includes a built-in browser for searching the web for manga and an offline translator that reads text from manga pages.

KotlinAndroid (native)
  • Browse and read manga from several public manga APIs
  • Built-in browser for searching the web for manga
  • Library page for saving manga to read later
  • Offline manga translator using OCR: it detects text on a page and translates it without an internet connection
  • Native Android experience

An open-source Kotlin manga app from GitHub, extended with our own features. Link leads to Github repospitory of the project (still in development)
